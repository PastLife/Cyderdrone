# CyberDrone Platform

ต้นแบบเว็บระบบขออนุญาตบินโดรน และแจ้งเบาะแสโดรนไม่ทราบที่มา
ธีม Cyber Dark ตาม PRD — สร้างด้วย Next.js 14 (App Router) + Tailwind CSS

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

> ตอน `npm install` และ `npm run build` ต้องต่ออินเทอร์เน็ต เพราะดึงฟอนต์ Kanit / JetBrains Mono จาก Google Fonts

## หน้าในระบบ

| เส้นทาง | ใช้ทำอะไร |
| --- | --- |
| `/` | หน้าแรก — เรดาร์เขตบิน สถิติ ทางลัด |
| `/permit` | ยื่นคำขอบิน + ปักหมุด + ตรวจเขตห้ามบินสด ๆ |
| `/permit/status` | ค้นสถานะด้วยรหัส PMT- หรือ RPT- |
| `/report` | แจ้งเบาะแสโดรน + ดึงพิกัด GPS + แจ้งแบบไม่เปิดเผยตัวตน |
| `/admin` | ภาพรวมเจ้าหน้าที่ — กราฟ 7 วัน แผนที่รวมเหตุ เรื่องค้าง |
| `/admin/permits` | อนุมัติ / ไม่อนุมัติคำขอ พร้อมเหตุผล |
| `/admin/reports` | จัดการเคสเบาะแส + ส่งออก CSV |

## โครงสร้างไฟล์

```
src/
  app/
    api/permits/…        REST สำหรับคำขออนุญาต
    api/reports/…        REST สำหรับเบาะแส
    permit/ report/ admin/
  components/
    ZoneMap.jsx          แผนที่ SVG กดปักหมุดได้ (หัวใจของระบบ)
    SiteNav, AdminNav, StatusBadge, StatusLookup, CountUp
  lib/
    zones.js             เขตห้ามบิน + สูตรคำนวณระยะและความเสี่ยง
    db.js                ฐานข้อมูลจำลองในหน่วยความจำ
```

## สิ่งที่ยังเป็นของจำลอง (ต้องเปลี่ยนก่อนใช้จริง)

1. **ฐานข้อมูล** — `src/lib/db.js` เก็บใน memory ข้อมูลหายเมื่อรีสตาร์ต
   ให้เปลี่ยนเป็น PostgreSQL + PostGIS โดยแก้แค่ไฟล์นี้ ส่วน API route ไม่ต้องแก้
2. **แผนที่** — ตอนนี้เป็น SVG ที่วาดเอง ทำให้รันได้โดยไม่ต้องมี API key
   ถ้าจะใช้ Mapbox GL JS ให้เปลี่ยนเฉพาะ `ZoneMap.jsx` โดยคงพร็อพเดิมไว้
3. **เขตห้ามบิน** — พิกัดใน `zones.js` เป็นข้อมูลตัวอย่าง ต้องแทนด้วยชั้นข้อมูลจริง
4. **ล็อกอินและสิทธิ์** — `/admin` ยังเปิดโล่ง ของจริงต้องมี Authentication + RBAC
5. **อัปโหลดไฟล์** — เก็บแค่ชื่อไฟล์ ยังไม่ได้ส่งขึ้น S3/Cloudinary
6. **ใบอนุญาต PDF + QR** — ยังไม่ได้ทำ

## ข้อควรระวังด้านกฎหมายและข้อมูล

- อำนาจออกใบอนุญาตบินโดรนเป็นของ CAAT และการขึ้นทะเบียนเป็นของ กสทช.
  ระบบนี้จึงควรวางเป็น "ระบบขออนุญาตภายในพื้นที่ของหน่วยงาน" ไม่ใช่ใบอนุญาตตามกฎหมาย
- ฟอร์มเก็บเลขบัตรประชาชนเฉพาะ 4 หลักท้าย ตามหลักเก็บข้อมูลเท่าที่จำเป็น (PDPA)
